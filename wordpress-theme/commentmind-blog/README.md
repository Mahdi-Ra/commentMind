# CommentMind Blog WordPress Theme

A dependency-free WordPress theme for `blog.commentmind.website`.

## Install

1. Zip the `commentmind-blog` directory.
2. In WordPress, open **Appearance > Themes > Add New > Upload Theme**.
3. Upload the zip and activate **CommentMind Blog**.

## Per-article FAQ

Edit a post and find the **Article FAQ** panel below the editor. Add as many question-and-answer pairs as needed. The theme displays them at the end of the article and outputs FAQPage JSON-LD for search engines.

## Table of contents

Use `H2` and `H3` headings inside article content. The theme automatically creates stable anchor IDs and renders a table of contents on the article page.
